# RD Enterprises website

Original multi-page website for RD Enterprises, developed as a local-only Vite project.

## Local development

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Open `http://127.0.0.1:5173/`.

## Production build

```bash
npm run build
npm run preview -- --host 127.0.0.1
```

The production output is generated in `dist/`.

## Pages

- `/` — Home
- `/about.html` — About
- `/services.html` — Complete civil and renovation service range
- `/gallery.html` — Filterable project gallery with lightbox
- `/contact.html` — Contact details and WhatsApp enquiry composer

## Content notes

- Establishment year: 2018.
- Positioning: Civil Contractor & Supplier; registered with MSME and on GeM.
- Project imagery is copied locally from the authorized shared project gallery.
- The enquiry form prepares a WhatsApp message locally. It does not send data until the visitor confirms in WhatsApp.
